# Phase 9 Figure Source Standard

Date: 2026-07-26

Every manuscript figure must have an independent directory. Shared directories
containing only flattened exports are no longer accepted for new Phase 9
figures.

## Required directory structure

```text
figures/phase9_submission/
  figN_short_name/
    README.md
    figure_spec.md
    figN_short_name.drawio
    figN_short_name.pdf
    figN_short_name.svg
    figN_short_name.png
    data/
      source files or immutable snapshots
      derived plotting CSV/JSON
    scripts/
      drawio_live_client.mjs
      build_drawio_live.mjs
      deterministic extraction or validation scripts
    provenance/
      SOURCE_MANIFEST.json
      ARTIFACT_SHA256SUMS.txt
```

## Draw.io requirement

- Create and edit the figure through the Draw.io Scientific Illustrator live
  MCP and draw.io's graph API.
- Do not generate draw.io XML first.
- Do not use operating-system mouse or keyboard automation.
- Keep panel labels, text, arrows, legends, axes, markers, and separators
  editable.
- Save the `.drawio` snapshot only after the visible canvas has been drawn.
- Validate the saved document and export PDF, SVG, and 2000-pixel PNG.
- Pin the live draw.io client inside each figure's `scripts/` directory so that
  the directory can be rebuilt without importing another figure's assets.

Dense numeric plots may use editable draw.io primitives. If a plot must retain a
non-editable raster element, the directory README must identify that element,
its generating data and script, and why it was not represented as primitives.

## Data and provenance requirements

1. Every number shown in a figure must appear in a retained CSV/JSON file.
2. Every source artifact must have an absolute development path, immutable hash,
   score definition, and permitted claim.
3. Derived files must be generated by a retained deterministic script.
4. The source manifest must distinguish frozen source data from derived display
   data.
5. Figure captions must state analysis units, aggregation order, uncertainty
   convention, and graph-object semantics.
6. MoCap panels must explicitly state that no direct graph ground truth is
   available.
7. H=64/H=128 panels must state that mass beyond H=128 was unassessed.

## Visual system

- Use one neutral base, one raw-route blue, and one auxiliary-route muted red.
- Reserve dark grey for text and axes; use muted teal only for total raw-chain
  attribution where needed.
- Avoid saturated fills and large colored backgrounds.
- Use 7.5--9 pt final-size sans-serif text inside figures.
- Use horizontal or vertical connectors; diagonal arrows are prohibited in
  architecture schematics.
- Separate panels with restrained dashed boundaries and compact internal
  spacing.
- Do not encode the same categorical distinction with inconsistent colors
  across figures.

## Final Phase 9 main figures

1. `fig1_route_coverage_framework`: conceptual architecture, derivative
   decomposition, and audit profile.
2. `fig2_controlled_decoupling`: Phase 8 controlled capacity, coefficient,
